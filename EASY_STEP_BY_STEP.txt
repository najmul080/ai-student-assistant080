# VERY EASY STEP-BY-STEP

1. Extract the ZIP.
2. Open app.py.
3. Replace YOUR_STUDENT_ID with your real Student ID.
4. Create a GitHub repository named `easy-ai-cloud`.
5. Upload ONLY:
   app.py
   requirements.txt
   README.md

6. Open Render.
7. New -> Web Service.
8. Select your GitHub repository.

Use:
Build Command:
pip install -r requirements.txt

Start Command:
gunicorn app:app

9. In Render -> Environment Variables add:

GEMINI_API_KEY = your Gemini API key

10. Deploy.
11. Open the Render URL.
12. Ask: "What is cloud computing?"
13. If AI answers, DONE.

IMPORTANT:
Do not put your API key inside app.py.
